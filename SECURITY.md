# Security Policy

This is the default security policy for byteshiftlabs repositories that
don't define their own.

## Reporting a Vulnerability

Please report security vulnerabilities privately using GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
feature on the affected repository (**Security** tab → **Report a
vulnerability**), rather than opening a public issue.

If a repository has private reporting disabled, open an issue describing
that a vulnerability report needs a private channel, without details of the
vulnerability itself, and wait for a response before disclosing further.

## Scope

These are independent projects maintained outside of full-time work. There
is no guaranteed response time, but reports are read and taken seriously.
